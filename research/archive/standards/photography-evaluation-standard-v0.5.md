# 摄影评价标准 v0.5（公开共识试运行修订版）

版本日期：2026-09-03  
适用阶段：摄影教练 Skill 与轻量反馈界面的内容标准  
适用输入：用户上传的一张照片；拍摄意图可选，不是前置义务  
当前状态：已通过受控缺陷先导测试与10例公开人类点评试运行；尚未通过30例正式验证，不得宣称“客观审美评分”

## 1. 产品承诺

本标准不替用户宣布照片绝对好坏。它的承诺是：

> 根据可见画面证据，先指出照片已经成立的关系，再判断是否存在一个真正影响表达的首要瓶颈；如果存在，把它转成下一次能验证的拍摄动作。如果不存在，只提供不破坏当前核心的可选实验。

这里的“客观”只表示过程可复核：事实、推断、意图条件和偏好被分开；证据能在画面中定位；建议不违反成像约束；同一输入重复评价时核心方向不应无理由漂移。它不表示存在唯一正确审美。

## 2. v0.5 为什么修订

v0.4 的受控变体测试证明系统能识别明显模糊、压缩、高光损失和重噪点，也证明单次小数分数不稳定。随后的[10例公开人类共识盲测（历史报告保留在本地）](../../README.md#本地原始研究资料)进一步暴露三类内容错误：

1. **风格误判**：B06 的蓝色是内部统一、被多人认可的表达选择，系统仍把非自然色升成首要问题，漏掉多人重复的景深问题；
2. **强制挑错**：B08 的暗调和微小光轨得到一致肯定，系统却因为格式强制要求“最大瓶颈”而把它们判成问题；
3. **优先级偏抽象**：B04、B07 的结构解释有证据，但系统漏掉更具体、影响广、低意图依赖的蒙版残色、清晰度、红色亮斑和水印。

试运行中，8个案例形成可比较的重复主题，首要判断完全匹配4例、部分匹配1例、不同但有证据3例；完全或部分匹配为5/8。该数值不能外推为产品准确率，但足以要求标准先修订再扩大样本。

## 3. 依据与证据层级

评价维度吸收但不机械照搬以下依据：

- [PPA 影像要素](https://www.ppa.com/ppmag/articles/12-elements-of-a-merit-image)：影响力、技术、构图、光线、主体、叙事、创意与风格等是可用的观察词典；竞赛／商业语境不等于所有摄影类型；
- [World Press Photo 评审流程](https://www.worldpressphoto.org/contest/judging-process)：视觉质量必须与故事、呈现、语境、准确性和代表性一起考虑；
- [NIMA](https://www.research.google/blog/introducing-nima-neural-image-assessment/)：技术质量与审美质量不是同一变量，人类判断应以分布和不确定性表达，而不是伪精确单点；
- [PhotoEye / PhotoBench（CVPR 2025）](https://openaccess.thecvf.com/content/CVPR2025/html/Qi_The_Photographers_Eye_Teaching_Multimodal_Large_Language_Models_to_See_CVPR_2025_paper.html)：一般图像识别不等于专业摄影理解，评价必须覆盖具体摄影问题；
- [RPCD 官方数据说明](https://github.com/mediatechnologycenter/aestheval/blob/main/data/datasheet.md)：社区点评高度主观，不应用来评价摄影者技能。v0.5只用其重复主题检验单张照片诊断，不把社区共识称为专家真理。

证据优先级：

1. 同一照片的可见事实、受控变体与重复运行；
2. 同一照片下多位独立评论者重复的具体关系；
3. 有透明方法的专业评审准则和摄影理论；
4. 单一评论者、点赞、流行风格与模型自我判断。

低层证据可以否定高层猜测。例如眼睛确实不在可接受焦面内，不能因为故事感强而说技术没有损失；反过来，技术损失也不自动否定照片的表达价值。

## 4. 两遍输入，不要求用户先解释

### 4.1 第一遍：盲读

只看照片，隐藏作者、题名、奖项、来源、点赞和评论。用户不必先回答“为什么按下快门”。盲读输出：可见事实、暂定类型、暂定解读、最成立的一点、是否存在结构性瓶颈，以及置信度。

### 4.2 第二遍：语境复核

盲读完成后，可以邀请用户补充一句意图，但必须允许跳过。新增语境只能调整：

- 意图契合；
- 故事／意义；
- 风格取舍是否有意识；
- 练习方向。

新增语境不能倒改像素事实，例如焦点位置、裁切关系、边缘高光或色彩残留。两遍结论变化时，必须指出是哪条新增信息造成变化。

## 5. 四类陈述与禁区

| 代码 | 类型 | 定义 | 允许语气 |
|---|---|---|---|
| F | 可观察事实 | 能由像素位置或可靠元数据核验 | 明确陈述 |
| E | 效果推断 | 事实明确，观看影响仍需推断 | “更容易”“可能先看到” |
| I | 意图条件 | 是否成立取决于作者目标或使用语境 | “如果…则…” |
| P | 审美偏好 | 存在多个合理方向 | 并列选项与代价 |

单张照片通常不能确认：作者身份、人物身份与关系、是否摆拍或征得同意、器材、焦段、快门、光圈、ISO、滤镜、灯具、精确机位、拍摄动机、动作前后事件，以及柔化究竟来自失焦、运动、压缩还是镜头特性。

可以由画面确认“存在多阶段太阳，因此不是同一单次曝光同时记录”；不能据此确认各阶段是否保持原始位置、是否同日或是否移动过。

## 6. 先判断类型，再选择适用关系

六维框架保留，但第四维从“瞬间与人物关系”改为更通用的“关键关系”。每维允许标为 N/A；N/A 不得按零分处理，也不得进入综合区间。

| 通用维度 | 所有题材都问什么 |
|---|---|
| 技术可读性 | 清晰、曝光、噪点、色差、压缩和处理是否让关键信息可读？ |
| 注意力组织 | 第一眼在哪里，之后如何移动；边缘、层次、重叠和空间是否支持这一顺序？ |
| 光线、影调与色彩 | 光和色如何塑造主体、空间、材质、时间和情绪？ |
| 关键关系 | 该类型最关键的对象之间是否形成有意义的联系？ |
| 信息与意义 | 画面是否提供足够线索形成情绪、地点、事件、疑问或概念？ |
| 表达一致性与完成度 | 形式选择是否内部一致；低层执行错误是否打断整体？ |

题材适配：

| 类型 | “关键关系”的主要对象 | 不能机械套用 |
|---|---|---|
| 街头／纪实／旅行人文 | 手势、视线、人物间距、环境线索、事件时机 | 不能要求背景一律虚化或技术绝对干净 |
| 人像／环境人像 | 目光、姿态、面部塑形、人与环境、用途 | 不能把商业头像光比当成自然人像唯一标准 |
| 风景 | 空间层次、天气、尺度、路径、自然与人为痕迹 | 没有人物或“决定性瞬间”不自动减分 |
| 建筑 | 几何、重复、尺度、材质、使用痕迹、透视 | 透视汇聚可以是表达选择，不必一律校正 |
| 微距／静物 | 焦平面、材质、形状节奏、色彩、背景分离 | 浅景深和非自然色不自动是缺陷 |
| 动物 | 眼神、姿态、行为时机、环境与安全距离 | 不从表情拟人化推断情绪事实 |
| 概念／合成 | 变换规则、元素一致性、观看逻辑、用途所需真实性披露 | 不拿纪实真实性要求直接否定明确创作性合成 |

类型不确定时最多保留两个候选类型，说明哪条判断会随类型变化。

## 7. 评价流程

### 第一步：文件与画面事实

记录分辨率、方向、明显压缩、EXIF可用性、可见主体、亮暗区域、色彩锚点、边缘侵入、清晰区域和重叠关系。不在这一步使用“漂亮”“高级”“有故事”等评价词。

### 第二步：暂定解读与最成立的一点

用一句话说明画面当前传达什么并给置信度。随后只选一个最成立的关系，至少定位两个证据。鼓励必须有证据，不使用“很有潜力”“继续加油”。

### 第三步：生成瓶颈候选

从以下五层各检查一次，不要求每层都有问题：

1. 关键技术可读性：眼睛、手势、文字或主体是否因焦点、曝光、压缩而不可读；
2. 低层执行：边缘色差、光晕、蒙版漏色、灰尘、水印、截断高光、明显拼接不一致；
3. 注意力与空间：高显著干扰、边缘切割、重叠、观看路径、尺度失衡；
4. 关键关系与时机：手势、目光、动作、焦平面、形状、层次或时间关系；
5. 意义与形式：概念是否成立、形式是否统一、语境是否不足。

低层问题不是天然比意义重要，抽象解释也不是天然更高级。它们必须进入同一优先级比较。

### 第四步：瓶颈优先级

每个候选只用整数档做内部排序，不向用户显示伪精确总分：

| 因素 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 影响范围 | 几乎不影响 | 局部细节 | 改变观看顺序 | 破坏核心信息 |
| 证据强度 | 无法定位 | 一个弱证据 | 两个清楚证据 | 多个相互支持证据 |
| 修复收益 | 改后无明显差异 | 细调 | 能明显改善层级 | 能恢复核心关系 |
| 意图依赖扣分 | 不依赖意图 | 有些依赖 | 高度依赖 | — |
| 核心取舍代价扣分 | 不伤核心 | 有轻微代价 | 会改变作品核心 | — |

内部优先级参考：

`影响范围 + 证据强度 + 修复收益 - 意图依赖 - 核心取舍代价`

它是防止任意挑选的排序工具，不是审美公式。分数接近时，优先选择：

1. 更具体、低意图依赖的问题；
2. 能由下一次拍摄验证的问题；
3. 修复后不破坏照片最成立之处的问题。

### 第五步：决定“瓶颈”还是“可选实验”

只有同时满足以下条件，才输出“首要瓶颈”：

- 至少两个画面证据；
- 对核心观看或表达产生明确影响；
- 不是仅因为偏离自然色、三分法、绝对锐利或流行风格；
- 不是照片已经成立且内部一致的核心取舍；
- 建议带来的收益大于对当前优点的损失。

否则输出：

> **当前没有需要重构的瓶颈。** 这张照片最重要的关系已经成立。下面的建议是一个可选实验，不代表当前做法错误。

不得为了显得专业而强制挑错。

## 8. 风格选择何时可以成为问题

黑白、颗粒、暗调、倾斜、模糊、浅景深、非自然色、强饱和、选择性色和大留白都不是自动缺陷。只有出现以下至少一种情况，才可成为瓶颈候选：

1. 关键对象因此不可读，例如双眼焦点落空；
2. 同一形式执行不一致，例如蒙版漏色、色光无意溢到脸部；
3. 形式造成多个高显著区域竞争，破坏已识别的观看顺序；
4. 与作者已知意图或用途直接冲突；
5. 同图受控变体证明技术损失，而系统又没有说明表达收益。

“我不喜欢这种风格”只能标为 P 类偏好，不能成为唯一瓶颈证据。

## 9. 区间评分

每个适用维度用 0–5 锚点和区间，不显示小数总分：

| 锚点 | 含义 |
|---:|---|
| 0 | 该维度核心信息不存在或明显违背已知意图 |
| 1 | 严重问题主导观看，几乎没有有效支撑 |
| 2 | 局部成立，但问题明显大于优点 |
| 3 | 基本成立，有清楚改进空间 |
| 4 | 多数选择成熟且互相支持 |
| 5 | 在该类型中形式、内容和取舍高度统一 |

置信区间：高置信度 ±0.25，中 ±0.5，低 ±1.0。缺少意图、文件质量不足、文化语境敏感或维度适用性弱时，不得给高置信度。

不输出跨题材排行榜。用户纵向练习只有在相同任务、相似条件、重复评价的区间发生实质分离时，才提示进步或退步。

## 10. 建议的完整格式

每条现场建议必须包括：

1. **动作**：移动多少、等待什么、改变距离／光线／焦平面或拍摄时机；
2. **预期效果**：哪条观看关系会改变；
3. **代价**：会失去什么当前优点；
4. **可得性**：即时可做／需要相似场景／依赖稀有事件；
5. **替代练习**：非即时建议必须给一个20–40分钟内可完成的替代练习。

不能只说“换角度、突出主体、注意构图、后期调一下”。不默认推荐购买器材。

成像约束：

- 改变快门、光圈、ISO必须说明保持曝光需要的补偿；
- 锐化不能恢复真正错失的焦点；
- 降噪会损失纹理，提亮暗部可能放大噪点与色偏；
- 裁切不能恢复画外信息，并会降低输出像素；
- 背景虚化同时受光圈、焦距、拍摄距离和主体—背景距离影响；
- 单张成片不能可靠区分相机抖动、主体运动、失焦和平台压缩；
- 合成作品涉及元素移动或重排时，应按用途说明真实性边界。

## 11. 后期边界

后期建议与重拍建议分开。优先顺序：

1. 先移除明显低层执行干扰：灰尘、蒙版残留、色差、光晕、无意水印／亮点；
2. 再调整局部亮度、色彩和裁切以强化既有关系；
3. 最后才讨论风格性调色。

若处理会改变记录事实、移动人物／太阳／建筑或生成不存在的内容，必须明确标为合成／生成式编辑，不得包装成普通调色。

## 12. 参考图与摄影师方向

反馈通过内容门槛后，最多提供两层参考：

1. **可合法展示的方法图例**：公共领域、CC0、CC BY或CC BY-SA；必须保存作者、来源和许可，只讲一个与本次动作一致的方法；
2. **摄影师／作品方向**：优先摄影师本人、基金会、博物馆、Magnum或出版社官方页面；没有开放许可时只链接，不复制图片。

参考必须匹配方法而不只是题材。例如建议是“让人物在明暗交界与竖线分开”，图例必须真的呈现该关系；不能只因为同样是街拍就推荐布列松。名气不能作为本图评分证据。

## 13. 用户反馈卡顺序

1. 我怎样读这张照片（暂定解读＋置信度）；
2. 最成立的一点（两个证据）；
3. 决策：首要瓶颈，或“无结构性瓶颈＋可选实验”；
4. 画面证据；
5. 同场景重拍动作、效果、代价与可得性；
6. 后期能做／不能做；
7. 20–40分钟练习；
8. 方法图例和摄影师方向；
9. 六维区间、N/A和未知项；
10. 可选语境复核：用户愿意时再补充意图。

默认首屏只显示1–5；其余渐进展开，避免一次呈现所有摄影术语。

## 14. 30例正式验证规则

### 14.1 样本

- 至少18例街头／旅行人文；
- 其余覆盖人像、风景、建筑、微距／静物、动物与概念／合成；
- 强、中、弱作品都要有；
- 每例至少3条实质顶层点评；
- 至少2位不同评论者重复同一具体关系，才标“重复主题”；
- 正向重复主题也进入分母，用于检查系统是否过度挑错；
- 无重复主题保留为不确定性样本，不因难比较而删除。

### 14.2 对照

- 对负向共识：比较系统首要瓶颈与最强重复问题；
- 对只有正向共识的案例：正确行为是最成立的一点对齐，且不凭空制造破坏核心的瓶颈；
- 对分歧案例：检查系统是否明确条件分支和代价；
- “完全匹配”必须同对象、同关系、影响相近，不能只共享大类词。

### 14.3 暂定门槛

| 指标 | 门槛 |
|---|---:|
| 完全或部分匹配 | ≥75% |
| 完全匹配 | ≥40% |
| 首要判断含至少两个位置证据 | ≥90% |
| 无依据事实断言 | ≤5% |
| 明显不可执行重拍建议 | ≤10% |
| 非即时建议正确标注可得性 | ≥90% |
| 只有正向共识时仍强制挑错 | ≤10% |
| 分歧样本表达不确定性／条件分支 | ≥80% |
| 建议含动作、效果、代价 | ≥90% |

通过只表示内容与公开点评重复主题具有可解释的一致性，不表示专家认证、界面好用、长期能学会或愿意付费。

## 15. Skill 回归要求

在封装为 Skill 后至少检查：

- 同一图片匿名改名运行5次，首要决策“瓶颈／可选实验”一致率≥80%；
- 首要瓶颈对象一致率≥80%，若变化必须来自接近的候选并说明；
- B06 不再因为非自然蓝色自动压过景深；
- B08 允许“无结构性瓶颈”；
- B04 先检查蒙版残色，B07先检查清晰度／红色亮斑／水印；
- B10 保持眼部焦点优先且不武断断言ISO或失焦成因；
- 所有外部参考链接可追溯，许可不明图片不进入本地界面。

## 16. 尚未解决

- 公开社区重复主题不是专家真理；
- v0.5 尚未完成30例正式盲测；
- 评分区间的跨运行稳定性仍需20图×5次复测；

因此对外措辞应是“基于画面证据的摄影诊断与练习”，而不是“AI客观裁判”或“权威评分”。
