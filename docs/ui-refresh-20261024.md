# 界面改版记录 · 2026-10-24

## 范围

本轮只改现有首页、报告模板和公开示例。未新增上传工作台、在线评图或 API 调用；未改 Skill 规则、八维评分、示例点评、参考作品和照片文件。没有新增前端依赖。

以摄影杂志与看片桌为方向，采用原生 CSS。保留原有品牌、导航名称、路由及锚点；统一暖白／炭灰主题和陶土色强调色。照片保持原比例完整显示，界面不再用标签覆盖对照图。控件为 4px 圆角，面板为 8px 圆角；照片本身不加滤镜或圆角。

- 首页：缩小导航高度，调整标题、留白、照片边框和版本按钮，整理功能说明的阅读顺序。
- 点评：首屏突出照片、结论和本次重点；桌面具体点评与原图并排，原图在阅读过程中跟随；窄屏改为普通单栏。
- 完整检查：六项内容保留在原生展开控件中，八维评分仍全部展示。
- 主题：报告也支持手动深浅切换，默认跟随系统；尊重减少动态效果设置。
- 图片加载：首屏不同时请求三个版本，另两个版本在切换或对照时请求；下方图片使用浏览器延迟加载。

## 检查结果

- 177 项 Python 测试；首页与报告两组 JS 检查。报告新增主题、延后加载、无标记时的单栏回退检查，原有四种图片组合与空参考状态仍覆盖。
- 真实浏览器检查了浅色／深色、桌面／窄屏。首页检查 320、768、1024、1440 像素宽度；报告检查 320、390、1280、1440 像素宽度，未发现页面横向溢出。320/390 像素窄屏上照片与评分为单栏。
- 实测照片版本切换、滑块方向键、具体点评标记、完整检查展开、安装请求及练习说明复制。复制失败回退路径由 JS 测试覆盖。
- 实测下载裁切调色版本，其 SHA-256 与原尺寸交付文件一致，不是预览小图。
- 公开示例的嵌入 JSON 与改版前完全一致；模板重新生成结果与已提交路径中的示例文件一致。
- README 两张截图来自此次实际浏览器页面，均为 1440×960 JPEG，不是生成的界面效果图。

这些检查仅覆盖已有示例及离线测试，不证明所有摄影题材、所有浏览器或点评质量已经通过验收。

## 性能边界

本机受限预览服务的 Lighthouse 移动端模拟结果：首页与报告的可访问性、最佳实践均为 100，性能均为 75；两页累计布局偏移为 0。此结果是单次实验室检查，不是线上速度或完整无障碍认证。

弱网仍是遗留问题：现有预览 JPEG 约 1.7 MB/张。报告延后加载后，本次首屏最大内容绘制从约 26.9 秒降到约 14.3 秒，首页约 9.6 秒，仍未达成理想加载目标。照片与下载文件本轮未压缩或重画；后续可单独增加小尺寸、高效编码的网页预览，同时保留原尺寸下载。不能把这轮视觉美化宣称为性能优化已完成。

浏览器预览只在本机环回地址开放明确列出的公开 HTML、CSS、JS 与示例图片，不提供仓库目录列表、私人研究材料或上传接口。
