- `python -m app.server` 启动，默认 `http://127.0.0.1:8768/`；Python 标准库服务、原生 HTML/CSS/JS、现有 Pillow，无新增框架依赖。
- 明确分开的免密钥公开案例与自己照片流程；上传、模型配置、显式费用确认、单任务处理和停止等待。

- 仓库外本机记录、刷新／重启恢复；密钥只在服务内存。失败不套用案例，不自动重试；重复请求有持久化标识。
- 保留 Skill、报告模板、既有示例；共用摄影规则与结构校验。本轮没有改写摄影标准。
