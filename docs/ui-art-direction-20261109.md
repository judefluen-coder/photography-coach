# 摄影画册式界面 · 2026-11-09

## 为什么调整

使用者认为上一版过于死板、缺少艺术感。本轮只改现有首页和单张报告的视觉呈现，不新增独立工作台或在线点评，不改变评价规则、评分、参考作品、照片及下载文件。

设计方向是摄影画册与看片手记：保留现有暖白／炭灰和陶土色，不新增素材或图像滤镜；用排版与留白重新组织照片、文字及操作。

- 首页将标题独立成一行，左侧完整照片，右侧短说明与操作。窄屏回到自然阅读顺序，标题第二行略微缩进。
- 去掉照片外的圆角卡片、阴影及大面积按钮底色；版本选择用文字和下划线标识。
- 报告保留照片优先的结构，将重点从填色卡片改为有层次的标题、短注和分隔；八维评分全部展开，每项理由保留。
- 大标题、拍摄建议与参考作品名称采用衬线字体；连续点评仍采用无衬线字体。字体使用本机回退，不依赖远程字体请求。
- 保留深浅主题、键盘焦点、减弱动态设置、下载、版本对照与图上定位。没有滚动劫持、自动轮播或装饰动画。

## 边界

本次 Lighthouse 移动端模拟：首页与报告的可访问性、最佳实践均为 100，性能均为 75；累计布局偏移均为 0。首页 LCP 约 9.6 秒，报告约 14.3 秒。大预览图造成的弱网加载问题仍在，本轮不宣称已改善性能。这是本地单次实验室检查，不是线上体验或完整无障碍认证。

以上检查只验证界面与已有功能，不证明摄影建议更准确；视觉方向仍需使用者实际观看确认。独立上传工作台仍未接通。
