# v0.1.0 · 研究预览版

这是摄影教练的首个带版本号的公开快照，便于固定项目现状与后续迭代基线。它不是摄影点评质量已经通过独立盲测的正式版。

## 本版可以做什么

- 在 Codex 中安装并使用摄影点评技能，按画面证据获得评分、重点判断、重拍练习和具体作品参考。
- [打开完整静态报告示例](https://judefluen-coder.github.io/photography-coach/demo/)：切换原图、仅调色、裁切＋调色，查看点评并下载对应图片。
- 阅读[相邻产品的功能对比](https://github.com/judefluen-coder/photography-coach/blob/main/docs/alternatives.md)和[版本记录](https://github.com/judefluen-coder/photography-coach/blob/main/CHANGELOG.md)。

## 验证与限制

GitHub Actions 检查代码测试、知识结构、示例页面能否重建及基本交互脚本。摄影评价的独立新图盲测尚未达到正式发布门槛，自动化通过不代表点评一定准确。当前没有在线上传、自动修图服务或微信小程序。静态示例中的摄影作品及衍生图有单独的 [CC BY-SA 4.0 来源说明](https://github.com/judefluen-coder/photography-coach/blob/main/docs/demo/README.md)。仓库其他内容的复用许可请以仓库根目录的实际许可证与声明为准；公开可见不等于自动授权。
