# v0.2.0-alpha.2 · 单仓库整理

2026-10-19。把摄影教练的使用入口、研究和历史版本放回同一个项目，**不是新增可用 Web 工作台的版本**。

## 结构变化

- 保留根 `SKILL.md`、`app/`、`core/` 与当前 `references/`，不另建 Skill 项目或 `-v2` 仓库。
- 早期三案例界面源码进入 `docs/archive/prototype-v0.1/`，标记历史状态；`docs/demo/` 仍是当前完整公开示例。
- `research/` 收录五版历史评价标准、一次反馈模拟与六份研究协议／规范，并给出原始研究资料索引。
- 本地照片、评论、冻结答卷、第三方检出、历史报告和工具缓存集中在忽略的 `.local-data/`；不随 GitHub 或 Release 分发。
- 更新 README、安装方式、版本地图和贡献说明。推荐一份主仓库加 Skill 兼容链接，避免重复克隆。

## 核验与清理

维护者本机迁移的 6,553 个文件逐项核对通过；清理后的原始研究和报告再次核对通过。只清理了一份哈希完全一致的约 18.6 MB 工具依赖，移入废纸篓以便恢复；独有照片、代码、历史规范和失败记录没有删除。公开阅读版修正路径前的原文另存本地，冻结资料哈希保留。

177 项 Python 测试、页面逻辑检查、知识结构校验与 Skill 格式校验通过。公开 CI 缺少私有冻结包时明确跳过对应旧测试。工程检查不证明摄影质量；独立工作台仍未接通，本轮没有调用付费模型或新增摄影盲测。

GitHub 账户中只发现当前这一相关仓库；已有 `v0.1.0` 与 `v0.2.0-alpha.1` 保留，不覆盖标签或删除历史版本。
