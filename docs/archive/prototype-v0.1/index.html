                01
                我的第一眼
              

              

                我先看到的是渡轮和迎面下来的人，接着视线却被正中央的柱子和垃圾桶拦住了。你拍到了下船的忙乱感，只是这股人流还没在画面里连起来。
              

            


            

              

                02
                先说拍到的
              

              
左边的人往外走，船上的人迎面涌来——现场是动的

              
这两股相反的人流很重要。它让人感觉到“船刚靠岸”，而不是只看到一艘停着的渡轮。这个瞬间你抓到了。

            


            

              

                先改这一处
                让人流连起来
              

              
可惜正中间这根柱子，比人更抢眼

              

                柱子把船口和左边行人从中间劈开，下面的垃圾桶又占了一块最显眼的位置。结果是人明明很多，第一眼却不知道该跟着谁走。
              

              
灰天不是最要紧的。 灰色反而符合通勤的日常感。先把人物关系理顺，比加颜色更有用。

            


            

              

                03
                相似场景
              

              
如果我在你旁边，我会这样提醒

              
先别急着按，往右挪两三步

              

                
怎么做
让柱子避开船口，再等一个近处的人走进左边空处时按下快门。

                
会怎样
近处的人离开、远处的人涌来，两层动作能一口气读出来。

                
会失去
船身可能拍不全，码头设施也会少一些；但这张照片真正有意思的是人流，不是船的全貌。

              

            


            

              

                这张现在还能做
                
把柱子和垃圾桶稍微压暗一点，让它们别那么跳。

              

              

                但别指望后期做到
                
压暗只能减轻干扰，没法把被柱子隔开的两股人流重新接上。

              

            

          


          

            

              
01我为什么这么说

              
    
                
  1. 看正中间：柱子从上贯到底，刚好挡在船口人群前面。
    2. 
                
  2. 再看下面：垃圾桶又大又完整，比远处的人更容易先被看见。
    3. 
                
  3. 最后看左边：近处的人向左走，和船口迎面下来的人本来可以形成很好的一来一往。
    4. 
                
  4. 换句话说：问题不是画面里东西多，而是最显眼的东西没有帮你讲“人群下船”这件事。
    5. 
              

            


            

              
02把判断摊开看 · 不算总分

              

                
画面是否看得清3–4 / 5

                
视线有没有落点2–3 / 5

                
光和颜色是否帮忙3–4 / 5

                
人物与物件的关系2–3 / 5

                
有没有值得多看一眼3–4 / 5

                
整张照片是否说到一起2–3 / 5

              

            


            

              
03哪些是看到的，哪些还不知道

              
我能看到：人物站在哪里、往哪儿走，以及谁挡住了谁。

              
我由此判断：大多数人可能会先注意到柱子和垃圾桶，再去找人群。

              
单凭照片不知道：你当时为什么拍、能不能换位置，也不知道你用了什么器材和参数。

            

          


          

            

              
找半小时，拍 20 张

              
去拍一次“一近一远”

              
找一个车站、路口或出入口，先站到柱子不会挡人的位置。每张都同时留一个近处的人和一组远处的人；机位别动，只等不同的时机。

              

                回来看什么
                
把照片缩小。如果你还能一眼看出近处和远处的人各自往哪里走，这张就留下。

              

            


            

              
              

                
看一个相近的处理

                
这里也有柱子，但人流没有被截断

                
不用模仿地点和颜色，只看近处、远处的人怎么同时留在画面里。障碍物不必全清掉，关键是它有没有挡住最重要的动作。
