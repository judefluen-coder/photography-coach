## 已验证

- 三个示范案例均可切换：`NO_STRUCTURAL_BOTTLENECK`、`CONDITIONAL_BRANCH`、`STRUCTURAL_BOTTLENECK` 各一个；每例都有4条证据、6个维度、重拍/实验动作、练习和图例。
- 三张示范照片与三张方法图例均成功解码，并显示作者、来源和开放许可。
- “快评 / 证据 / 练习与参考”三个标签可切换，隐藏内容不会残留在无障碍树中。
- 上传本地图片后，只显示本地预览和“等待分析”，不会把示范答案冒充成新照片的反馈。
- “复制分析请求”成功写入剪贴板；失败时有手动复制回退。
- “返回示范”会回到上传前选中的示范；拍摄意图说明和大图对话框均可用。
- JavaScript 通过 `node --check`；浏览器控制台无报错。
- 500px 窄屏无横向溢出；桌面端保持左图右评，窄屏变为上下布局；示范选择器可横向容纳三个状态。

## 明确限制

- 这是研究界面，不含模型后端；用户自己的照片需附到 Codex 对话，由 `$photography-coach` 做真实分析。
- 示例图片通过相邻研究目录加载；移动整个界面目录时，需要同时保留对应图片或调整路径。
- 质检证明交互与结构可用，不证明摄影判断已经达到专家一致性，也不证明使用后能提升作品。
