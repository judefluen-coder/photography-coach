# Skill 启动 Web 应用 · 2026-11-17

## 交付

同一项目保留两种用法。安装 Skill 后发送「请用 $photography-coach 打开摄影教练」，启动随附工作台；直接附照片要求点评，仍使用原来的对话流程。打开应用无需照片、密钥或 MCP，不会自动上传附件或调用模型。Web 点评仍需自己的模型 API 和页面内费用／数据确认，不继承 Codex 订阅。

启动器位于 [`scripts/open_workbench.py`](../scripts/open_workbench.py)，普通用户也可脱离 Codex 运行。它核对健康身份、复用匹配服务或选择空闲 loopback 端口；只有 `--setup` 才允许在缺依赖时安装到项目虚拟环境。新版服务加载记录前对数据目录加 OS 文件锁，拒绝第二个服务；检测到旧版工作台则提示先关闭，不自动替换。
