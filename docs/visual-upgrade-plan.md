## 完成标准

- 首屏可以看懂是什么、打开完整示例、找到安装方法；无假上传、假在线 AI。
- 原图/仅调色/裁切版为既有真实文件；滑动对照仅用于原图与仅调色，下载仍对应完整版本。
- 缺少调色图、只有原图、旧双版本输入仍能正确使用；八维评分和具体作品链接不丢失。
- 桌面、手机无横向溢出；键盘可操作版本、滑动对照、定位和复制；复制失败有手动后备路径。

- README 截图来自实际页面，图像署名保留；正式摄影质量门槛仍如实披露。
