# 独立摄影工作台

在浏览器里上传照片、查看点评、继续提问，不需要安装 Codex。工作台在本机运行，使用你配置的模型 API；与 Skill 共用摄影规则、评分要求和报告模板。

当前为 `main` 分支上的实验版本，不包含在旧 alpha.3 标签中。已用模拟响应测试服务流程，**尚未完成真实 API 测试和摄影质量验证**。演示案例与自己的照片分开显示。

界面采用暗房工作台：桌面左侧是完整照片，右侧集中显示建议、八维区间和选中分数的理由；手机改为上下排列。点照片标记展开点评，点击评分在图旁更新依据，不自动跳页。无调色文件时直接展示后期建议，不空占一整栏。照片记录、完整分析、参考及练习保留，Skill 离线报告使用同一模板。

## 启动

需要 Python 3.11 或更新版本。在仓库根目录运行（macOS / Linux）：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r app/requirements.txt
python -m app.server
```

Windows 使用 `py -3 -m venv .venv`，然后在 PowerShell 执行 `.venv\Scripts\Activate.ps1`；后两条命令相同。打开 **http://127.0.0.1:8768/**，保持终端运行。无需 Node、数据库或 Codex。不要双击 `app/static/index.html`：选图、记录和模型调用需要本机服务。

端口占用时使用 `python -m app.server --port 8769`，按终端显示的地址打开。

## 使用方法

### 先看演示：无需密钥、不会调用模型

点击“演示案例”，在工作台里查看已有公开案例的全画面观察、八维评分、原图／仅调色／裁切＋调色和参考作品。页面明确标注演示，它不会出现在你的私人照片记录里。[图片来源与许可](../docs/demo/README.md)。

### 用自己的照片

1. 选择或拖入 JPG、PNG、WebP（不超过 16 MB、3000 万像素，不支持动画、RAW 和 HEIC）。这一步只保存到本机。
2. 点击“连接模型”，填写 API 基地址、可用的视觉模型名称与 API 密钥。**保存配置不发起模型请求**，也不验证账户额度。
3. 可选填写想讨论的问题。确认照片发送目的地和 API 费用后，点击“开始点评”。
4. 在当前页面阅读完整反馈；可追问、下载原始上传文件、导出离线报告。每次追问需另行确认调用。
5. 如果模型给出了有效调色参数，可点击“生成试调版（本机）”。它实际处理颜色／明暗，有必要时另生成裁切版，不另调用模型。
6. 有同取景调色文件时，可滑动对照、调节“影调强度”，并下载当前混合强度。它只在浏览器混合原图和已生成调色版，不是新一次模型调用或局部曝光测量；原始文件不覆盖。离线浏览器限制导出时，仍可下载原始调色文件。

主画布默认完整显示照片。“局部放大”只改变浏览视图，不拉伸、补画或保存裁切。选择裁切版时，原图坐标的标注会隐藏；点击一条画面观察会回到原图。

照片记录保存在本机。刷新或重新打开同一条记录不会重新调用模型；关闭服务再启动后，记录仍在，但需要重新配置密钥。

## 模型与费用

- 目前接入 **Responses 协议 + 图片输入 + 严格 JSON Schema 结构化输出**，不是仅支持 Chat Completions 的端点。默认基地址为 `https://api.openai.com/v1`，程序自动追加 `/responses`；模型名称由你填写。
- 第三方端点必须实现相同协议，尚无兼容性保证。只允许公开 HTTPS 443 地址，不支持本机模型或内网端点。
- 每次点评／追问发出一次请求，不自动重试。模型拒绝、超时、输出不完整或格式错误时，显示失败，不使用示例内容补齐结果。
- 输出 token 上限**不是金额上限**，也不包含输入 token。输出额度过低可能无法生成完整报告。已返回的 token 用量会保留，实际费用以供应商账单为准。
- “停止等待”会丢弃尚未提交的结果，**不保证远端停止计算或免除费用**。同一时间只执行一个任务，远端请求结束前不能开始下一次；关闭进程也不保证供应商停止计费。
- 协议依据：[图像输入](https://developers.openai.com/api/docs/guides/images-vision)、[结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs)。文档匹配不等于已完成实调用验收。

## 数据放在哪里

| 系统 | 默认私人数据目录 |
|---|---|
| macOS | `~/Library/Application Support/Photography Coach/workbench/` |
| Linux | `~/.local/share/photography-coach/workbench/` |
| Windows | `%LOCALAPPDATA%\Photography Coach\workbench\` |

也可以用 `--data-dir /path/to/new-private-folder` 指定仓库外的专用目录。拒绝仓库、家目录本身、符号链接及已有无关内容的目录；macOS / Linux 目录须只允许当前用户访问。原始文件、规范化显示副本、报告和对话都放在这里，不进入 Git 仓库。

- API 密钥只存于本机服务的进程内存，不写入文件、日志或浏览器存储；“清除当前密钥”不影响已经发出的请求。
- 原始上传文件按字节保留，可能仍含 EXIF。发送给模型的是去元数据、最长边 1600 像素的 JPEG 预览；报告使用经过方向校正与 sRGB 转换的无元数据显示副本。**报告里的“原图”不是相机原始字节文件**，后者可单独下载。
- 追问发送预览、当前点评、最近六轮对话和新问题。保存到本机不代表模型处理离线；不要发送没有处理权限的私人照片。
- ZIP 导出包含可独立打开的 HTML 和图片，不含密钥、服务内部 JSON 或原始文件元数据。ZIP 解压后打开 `index.html`；转移报告时保留 `assets/`。
- 已有报告可“移入回收区”，并非永久删除。手工恢复时先关闭服务，将 `trash/<记录 ID>-<后缀>/` 移回 `sessions/<记录 ID>/`，不得覆盖现有记录。

只监听 `127.0.0.1`，并检查 Host、Origin 与页面令牌。**这是单用户本机工具，不是公网服务**；不要改成 `0.0.0.0`、用隧道公开它或直接部署到云上。首版不提供登录、多人隔离、加密存储、云同步或磁盘配额。

## 功能限制

- **实时参考作品检索尚未接入。** 自己的照片会显示未检索状态。Skill 仍可按原有规则使用运行环境中的检索工具。
- 试调版使用有限的后期参数，不支持 RAW，也不使用生成式改图或增删物体。结果尚未经过独立视觉复核，不保证比原图好。没有明显像素变化时不生成调整版；没有有效参数时只显示建议。
- 追问不会更改第一版评分，也不能将新建议自动应用为第二版调色参数。
- 缩小预览可能漏掉细节；评分和点评可能出错，不是专家认证，也没有通过新的独立盲测。
- 本机浏览器验收、离线工程测试与真实模型质量是三件事。后者仍需明确调用账户、预算和授权后另验收。

## 开发验证

```bash
python -m unittest discover -s scripts -p 'test_workbench_*.py'
node --check app/static/app.js
```

服务测试启动真实 loopback HTTP 服务，将模型传输替换为明确的测试响应，覆盖上传、费用确认、密钥边界、取消、刷新／重启、重复请求、失败、追问、实际调色和导出；不访问模型服务，不产生 API 费用。测试替身不是运行时选项，也不是演示模式的数据来源。

代码位置：[`server.py`](server.py)（HTTP 与文件白名单）、[`workbench.py`](workbench.py)（会话／任务）、[`static/`](static/)（界面）、[`../core/`](../core/)（共用规则、校验与图像处理）。
