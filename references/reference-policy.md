# Reference and example policy

## Goal

A reference is useful only when it isolates the same photographic problem. Match a method—such as edge control, competing salience, gesture timing, figure-ground separation, tonal layering, or intentional occlusion—not prestige or superficial subject matter.

## Eligibility gate

Treat the bundled reference library as a verified starting set, not a closed catalogue. Do not select a card merely because retrieval ranked it highly. Before delivery, require all four conditions:

1. `User-image anchor`: name the two localized things in the user's photograph whose relation created the leading diagnosis.
2. `Reference-image anchor`: name the two localized things in the candidate photograph that demonstrate the same mechanism.
3. `Transfer`: give one shooting, selection, or editing experiment that tests that mechanism.
4. `Anti-imitation`: name one important difference that makes literal copying inappropriate.

Reject a candidate when the match is only a shared subject, genre, palette, mood word, composition label, or famous photographer. Visual resemblance may break a tie after the mechanism matches; it cannot create the match.

Search the bundled cards first because their identity and teaching notes have already been checked. When none clears the gate and web access exists, search outside the collection for an exact photograph and verify it under the source and display rules below. An externally found work may be used in the current critique without being silently added to the corpus. If no candidate clears the gate, say that no sufficiently related verified reference was found; never lower the threshold just to fill the section.

## Image display rule

Embed or redistribute an image only when the specific image page verifies one of:

- public domain;
- CC0;
- CC BY;
- CC BY-SA.

Carry author/creator, direct source page, exact license, and license URL. Follow attribution and share-alike conditions. A search-result thumbnail, “free wallpaper” claim, social repost, fair-use guess, or a photographer being deceased is not license evidence.

When permission is absent or unclear, provide a normal link to the photographer's, estate's, museum's, agency's, publisher's, or course provider's official page. Do not reproduce the image in the answer.

## Source quality

Prefer, in order:

1. photographer/estate/agency/museum official pages;
2. original contest or institutional archive pages;
3. course publisher or instructor's official syllabus/page;
4. Wikimedia Commons or another repository only when its file page identifies creator, provenance, and license.

Verify current URLs and terms when web access is available. Search snippets alone are insufficient.

## Match explanation

For every reference, state:

- a 20–60 second looking task that makes the user identify fixations, layers, lines, color anchors, or a key gesture before reading the explanation;
- which visible relation in the user's photo it addresses;
- what to inspect in the reference;
- one meaningful difference that prevents imitation-by-recipe;
- the experiment the user should transfer to their next shoot.

Phrase the comparison as a relation in both images, not as two parallel descriptions. The user should be able to point to the relevant locations before reading the explanation.

Do not use a famous name as evidence that the user's photo is good or bad. Do not imply stylistic resemblance proves intention.

## Default delivery

When web access exists, an ordinary single-photo critique should include one or two verified exact-image references without waiting for the user to ask again. Prefer a direct single-work page. A project, exhibition, or article page is acceptable only when the exact photograph is named by author, title/location, and year and its position on the page is unambiguous. Never send a bare portfolio, biography, search result, or undirected body-of-work link. Pair each reference with a short looking task so reference study is active rather than inspirational browsing. If the method match is weak, provide one strong photograph rather than two famous names.

Default to one reference. Add a second only when it teaches a different, explicitly named mechanism; do not use a second image merely for variety. State whether an image comes from the bundled verified set or a newly verified web result only when provenance would help the user, without turning the critique into database metadata.

## Courses

Recommend a lesson only when it directly addresses the diagnosed bottleneck and the official page confirms scope. Distinguish free/paid, language, and access date when available. Avoid dumping a generic course list into a single-photo critique.
